# RC Trainer Plane Dimension Calculator

A web-based calculator for preliminary dimensional design of RC trainer aircraft. Enter your desired wingspan to calculate the proportional dimensions of the aircraft, helping you plan your DIY foamboard or balsa RC trainer.

## Features

- **Wingspan Input:** Enter your desired aircraft wingspan.
- **Automatic Dimension Calculation:** Calculates the corresponding dimensions of the RC trainer aircraft based on proportional design parameters.
- **Unit Selection:** Supports centimetres (cm) and inches (in).
- **Aircraft Visualization:** View the generated RC trainer aircraft model.
- **Technical Drawings:** View aircraft dimension drawings for reference.

## Technology Stack

- React
- TypeScript
- Vite
- Three.js
- Tailwind CSS

## How to Run Locally

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/OmLCA/RC-Trainer-Plane-Dimension-Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd RCPlaneCalc
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
